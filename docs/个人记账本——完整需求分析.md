## 1. 项目概述

### 1.1 项目定位

**Ledger** 是一款开源、自托管、AI 驱动的个人云端记账系统。以「3 秒记账，AI 懂你的每一笔」为核心理念，提供自然语言记账、小票 OCR、智能预算、财务周报等 AI 能力，同时支持支付宝/微信账单导入、交易日历热力图、交易标签等实用功能。

| 维度         | 定位                                                         |
| :----------- | :----------------------------------------------------------- |
| **目标用户** | 个人终端用户（职场新人、大学生、自由职业者）                |
| **核心价值** | AI 驱动的极速记账 + 主动式财务洞察 + 开源自托管             |
| **部署方式** | Docker 一键部署，支持 MySQL + Redis + Milvus               |
| **开源协议** | MIT                                                          |
| **平台**     | 当前仅 Web 端，后续演进移动端 / 小程序 / 桌面安装           |

### 1.2 产品名称与 Slogan

```sql
CREATE TABLE `tag` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `user_id` bigint(20) NOT NULL,
  `name` varchar(50) NOT NULL COMMENT '标签名称',
  `color` varchar(20) DEFAULT NULL COMMENT '标签颜色（如#FF6B6B）',
  `sort_order` int(11) DEFAULT '0' COMMENT '排序',
  `is_deleted` tinyint(1) DEFAULT '0',
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_name` (`user_id`, `name`),
  KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### 3.3.5 定时交易表（scheduled_transaction）

```sql
CREATE TABLE `scheduled_transaction` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `user_id` bigint(20) NOT NULL,
  `name` varchar(100) NOT NULL COMMENT '计划名称',
  `type` tinyint(1) NOT NULL,
  `category` varchar(20) NOT NULL,
  `amount` decimal(10,2) NOT NULL,
  `remark` varchar(255) DEFAULT NULL,
  `cron_expression` varchar(50) NOT NULL COMMENT 'Cron表达式（如 0 0 0 1 * ? 每月1日）',
  `next_execute_time` datetime NOT NULL COMMENT '下次执行时间',
  `status` tinyint(1) DEFAULT '1' COMMENT '1-启用，0-暂停',
  `last_execute_time` datetime DEFAULT NULL,
  `last_execute_status` tinyint(1) DEFAULT NULL COMMENT '0-失败，1-成功',
  `is_deleted` tinyint(1) DEFAULT '0',
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_user_status` (`user_id`, `status`),
  KEY `idx_next_execute` (`next_execute_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 7. 风险分析

| 风险项                    | 影响 | 概率 | 缓解措施                                                     |
| :------------------------ | :--- | :--- | :----------------------------------------------------------- |
| **免费额度耗尽**          | 高   | 中   | 主备双模型 + 用户日限额 + 成本监控告警                       |
| **AI 解析错误率偏高**     | 中   | 中   | System Prompt 约束 + 结构化 Schema 校验 + 预览卡片           |
| **支付宝/微信账单格式变更**| 中   | 低   | 解析器做版本兼容 + 导入预览确认步骤                           |
| **Milvus 单点故障**       | 中   | 低   | Standalone 重启自动恢复 + RAG 降级跳过                       |
| **标签数据量膨胀**        | 低   | 中   | 标签列表 Redis 缓存 + 分页查询                               |
| **导入数据与手动记账冲突**| 中   | 中   | 按交易号/日期+金额去重 + 导入预览确认                       |
| **定时交易幂等失效**      | 中   | 低   | 幂等 Key = userId + scheduledId + 执行日期                   |
| **介绍页与 Vue 应用跳转**  | 低   | 低   | Nginx 路径分离 + 介绍页 CTA 直接跳 /app/login               |

## 9. 对标 ezbookkeeping 的功能取舍记录

| ezbookkeeping 功能        | 决策  | 理由                                       |

| 自动保存草稿               | ✅ P0  | 前端 localStorage 20 行代码               |
| 定时交易                   | ✅ P1  | 固定支出自动记账                           |
| 批量修改                   | ✅ P2  | 用户量不大时需求弱                         |
| 交易日历视图               | ✅ P0  | 最直观的月度复盘方式                       |
| 趋势同比/环比              | ✅ P1  | 积累数据后才有意义                         |
