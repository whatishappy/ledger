## 一、测试环境准备

### 1.1 环境要求

- JDK 21.0.10（`JAVA_HOME=C:\Program Files\Java\jdk-21.0.10`）
- MySQL 8.0+（已创建 `ledger` 数据库并执行 `schema.sql`）
- Redis 5.0+
- MinIO（图片存储，端口 9000/9001，bucket: `ledger-avatars`）（V2.1 新增）
- 应用启动：`mvn spring-boot:run` 或 `java -jar target/personal-ledger.jar`

### 1.2 测试前置条件
1. MySQL 中已执行 [schema.sql](file:///f:/ledger/src/main/resources/db/schema.sql)，13 张表创建成功（V1.5 基线 4 张 + V2.0 新增 9 张）
2. Redis 服务可访问（默认 `localhost:6379`）
3. MinIO 服务可访问（默认 `localhost:9000`，bucket `ledger-avatars` 已创建并设置公开读）（V2.1 新增）
4. `application-dev.yml` 中数据库/Redis/MinIO/AI 模型配置正确
5. AI 模型配置：主模型 Agnes（API Key 已配置）、备用模型 DeepSeek-V4-Flash、Embedding 模型 Qwen3-Embedding-0.6B-GGUF（V2.1 新增）

### 1.3 统一响应格式
所有接口返回 `Result<T>` 结构：
```json
{
  "code": 0,
  "message": "成功",
  "data": { ... },
  "timestamp": "2026-08-18T10:00:00"
}
```

## 三、核心设计验证清单

以下为 V1.4 详细设计的 5 项核心机制，**必须逐一验证**：

### 3.1 幂等设计（§5.3）

```
测试步骤：
1. 调用 POST /api/account/add，请求体：
   {"type":0,"category":"餐饮","amount":25.50,"accountDate":"2026-08-18","remark":"午餐"}
2. 记录返回的 accountId（例如 100）
3. 立即再次发送完全相同的请求
4. 预期：返回的 accountId 仍为 100（非新ID）
5. 查 DB：SELECT COUNT(*) FROM account_book WHERE user_id=? AND category='餐饮' AND amount=25.50
   预期：1 条记录
6. 等 5 分钟后再次发送 → 应生成新记录（幂等Key过期）
```

### 3.2 跨月缓存双清（§5.5）

```
测试步骤：
1. 调用 GET /api/statistics/dashboard?month=2026-08 → 写入 8 月缓存
2. 调用 GET /api/statistics/dashboard?month=2026-09 → 写入 9 月缓存
3. 修改账目：原 accountDate=2026-08-18 → 新 accountDate=2026-09-01
4. 再次调用 dashboard?month=2026-08 → 应重新查库（8月缓存已清）
5. 再次调用 dashboard?month=2026-09 → 应重新查库（9月缓存已清）
6. 验证日志：AccountChangeListener 输出两次缓存清除日志
```

### 3.3 乐观锁冲突（§5.5）

```
测试步骤：
1. 调用 POST /api/account/add 新增一笔账目，记录返回的 accountId
2. 调用 POST /api/account/page 查询该账目，记录 version（例如 1）
3. 发起修改A：version=1 → 成功（code=0），数据库 version 变为 2

### 3.4 用户版本号Token失效（§3.4）

```

## 七、常见问题排查

| 现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 编译失败"无法访问 MapperScan" | JDK 版本为 8 | 设置 `JAVA_HOME` 为 JDK 21.0.10 |
| 启动报错"Communications link failure" | MySQL 未启动或连接信息错误 | 检查 `application-dev.yml` 数据源配置 |
| 启动报错"Unable to connect to Redis" | Redis 未启动 | 检查 Redis 服务状态 |
| 接口返回 401 | Token 无效或已过期 | 重新登录获取新 Token |
| 接口返回 1004 | 用户版本号不匹配 | 用户被注销或 Token 已失效，重新登录 |
| 幂等未生效 | 幂等 Key 生成不一致 | 确认 5 分钟内相同参数；检查 MD5Utils |
| 跨月双清未触发 | 事件监听器未生效 | 检查 `@TransactionalEventListener(AFTER_COMMIT)` 注解 |
| 预算查询 SQL 过多 | N+1 未优化 | 确认使用 `sumSpentGroupByCategory` 而非循环查询 |
| 导出文件 404 | 文件已被清理或路径错误 | 检查 `export.file-path` 配置和文件是否存在 |
