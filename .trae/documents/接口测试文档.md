## 一、测试环境准备

### 1.1 环境要求

- JDK 21.0.10（`JAVA_HOME=C:\Program Files\Java\jdk-21.0.10`）
- MySQL 8.0+（已创建 `ledger` 数据库并执行 `schema.sql`）
- Redis 5.0+
- 应用启动：`mvn spring-boot:run` 或 `java -jar target/personal-ledger.jar`

### 1.2 测试前置条件
1. MySQL 中已执行 [schema.sql](file:///f:/ledger/src/main/resources/db/schema.sql)，4 张表创建成功
2. Redis 服务可访问（默认 `localhost:6379`）
3. `application-dev.yml` 中数据库/Redis 连接信息正确

### 1.3 统一响应格式
所有接口返回 `Result<T>` 结构：
```json
{
  "code": 0,
  "message": "成功",
  "data": { ... },
  "timestamp": "2026-08-18T10:00:00"
}
```

#### TC-A03：修改记账（跨月双清+乐观锁）

| 项 | 内容 |

| TC-A03-04 | 账目不存在 | `{"id":999999,...}` | code=2001 |

**⚠️ 关键验证（TC-A03-02 乐观锁）**：
```
1. 查询账目，记录 version=1
2. 用 version=1 发起修改A → 成功，数据库 version 变为 2
3. 用 version=1 再次发起相同修改 → code=2002
```

**⚠️ 关键验证（TC-A03-03 跨月双清）**：
```
1. 调用 /api/statistics/dashboard?month=2026-08 → 写入8月缓存
2. 调用 /api/statistics/dashboard?month=2026-09 → 写入9月缓存
3. 修改账目：accountDate 从 2026-08-18 改为 2026-09-01
4. 再次调用 dashboard?month=2026-08 → 应查库（缓存已清）
5. 再次调用 dashboard?month=2026-09 → 应查库（缓存已清）
```

### 3.1 幂等设计（§5.3）

```
测试步骤：

   预期：1 条记录
6. 等 5 分钟后再次发送 → 应生成新记录（幂等Key过期）
```

```
3. 修改账目：原 accountDate=2026-08-18 → 新 accountDate=2026-09-01
4. 再次调用 dashboard?month=2026-08 → 应重新查库（8月缓存已清）
```

## 七、常见问题排查

| 现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 编译失败"无法访问 MapperScan" | JDK 版本为 8 | 设置 `JAVA_HOME` 为 JDK 21.0.10 |
| 启动报错"Communications link failure" | MySQL 未启动或连接信息错误 | 检查 `application-dev.yml` 数据源配置 |
| 启动报错"Unable to connect to Redis" | Redis 未启动 | 检查 Redis 服务状态 |
| 接口返回 401 | Token 无效或已过期 | 重新登录获取新 Token |
| 接口返回 1004 | 用户版本号不匹配 | 用户被注销或 Token 已失效，重新登录 |
| 幂等未生效 | 幂等 Key 生成不一致 | 确认 5 分钟内相同参数；检查 MD5Utils |
| 跨月双清未触发 | 事件监听器未生效 | 检查 `@TransactionalEventListener(AFTER_COMMIT)` 注解 |
| 预算查询 SQL 过多 | N+1 未优化 | 确认使用 `sumSpentGroupByCategory` 而非循环查询 |
| 导出文件 404 | 文件已被清理或路径错误 | 检查 `export.file-path` 配置和文件是否存在 |
